## 四、Mock 策略

测试不依赖任何真实 LLM API Key。通过 `MockLLMProvider` 替代全局 `LLMProvider` 单例：

- **文本调用** (`chat`): 根据 `system_prompt` 内容判断是诊断/执行引擎/复盘 Agent，返回对应预设 JSON
- **多模态调用** (`chat_with_images`): 返回预设的图片解析数字
- **重试序列**: 支持设置有序响应序列，测试执行引擎的约束重试逻辑
- **调用记录**: 记录所有调用参数，用于断言 `json_mode`、调用顺序等
