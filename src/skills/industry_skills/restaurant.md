# 餐饮行业营销技能
# 版本: 1.0.0
# 适用行业: 餐饮/餐厅/饭馆

## 行业核心痛点
- 新店开业客流高峰后快速回落
- 复购率低（通常<20%）
- 外卖平台抽成高（20-30%）
- 食材成本波动大，利润难控
- 缺乏会员体系，客户粘性低

## 获客渠道优先级
1. **本地生活平台**（大众点评/美团）：核心获客渠道，必须做好评分和图片
2. **短视频**（抖音/视频号）：展示菜品、用餐氛围、厨师故事
3. **私域运营**：建立顾客微信群，做活动通知和优惠
4. **异业合作**：与附近健身房、美容院、写字楼合作
5. **美食KOL合作**：邀请本地美食博主探店

## 关键指标基准
- 日均客流量：50-100人（小餐饮）
- 客单价：50-150元
- 翻台率：中餐2-3次/台
- 复购率：目标30%+
- 外卖占比：20-40%

## 客户心理特征
- 追求便利：就近、快速、有停车位
- 重视体验：环境、服务、口味稳定性
- 社交属性：聚餐、拍照分享
- 价格敏感：但愿意为品质多付10-20%

## 推荐内容方向
- 菜品制作过程展示
- 后厨透明化（"干净厨房"主题）
- 顾客好评墙/评价截图
- 主厨故事/食材故事
- 优惠活动（开业周年、节日套餐）
- 顾客UGC（顾客拍的菜品图）

## 本周快速启动建议
1. 检查大众点评/美团店铺页面，补全菜品图和环境照
2. 建立顾客微信群，设置欢迎语和优惠规则
3. 拍摄3条短视频：招牌菜制作、后厨展示、顾客好评
4. 设计会员积分体系（消费1元积1分，积分换菜）
