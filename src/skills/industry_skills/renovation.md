# 家装行业营销技能
# 版本: 1.0.0
# 适用行业: 家装/装修/装饰

## 行业核心痛点
- 客户决策周期长（3-6个月），流失率高
- 价格透明度低，客户比价严重
- 施工质量纠纷多，口碑传播力弱
- 依赖小区楼盘驻点获客，成本高且效果递减
- 设计师能力参差不齐，转化能力不稳定

## 获客渠道优先级
1. **短视频（抖音/视频号）**：展示施工过程、案例前后对比，是当前ROI最高的渠道
2. **小红书**：针对改善型客户（30-45岁女性决策者），发布装修日记、避坑指南
3. **老客户转介绍**：家装天然具有社交属性，满意客户的转介绍成本为零
4. **本地生活平台**（大众点评/美团）：获取搜索型客户，需维护评分和案例
5. **小区楼盘合作**：成本高但精准，建议作为辅助渠道

## 关键指标基准
- 月均咨询量：30-50条（5人团队）
- 到店率：咨询→到店 30-40%
- 成交率：到店→成交 20-30%
- 客单价：基装10-20万，整装20-50万
- 毛利率：25-35%

## 客户心理特征
- 怕被坑：装修是大额消费，客户高度焦虑
- 重视口碑：更相信朋友推荐而非广告
- 需要安全感：合同、报价、材料明细必须透明
- 决策慢：需要多次沟通和对比

## 推荐内容方向
- 装修避坑指南（"10个装修后悔事"）
- 真实案例前后对比（改造前vs改造后）
- 施工工艺展示（"3分钟看懂水电改造"）
- 预算分配建议（"20万预算怎么分配"）
- 客户证言视频
