# 通用行业营销技能
# 版本: 1.0.0
# 适用行业: 未明确分类的小企业/其他行业

## 通用营销痛点
- 缺乏稳定获客渠道，过度依赖转介绍和自然流量
- 线上存在感弱，客户搜索找不到
- 内容营销能力不足，不知道发什么、在哪发
- 客户数据零散，没有系统化管理
- 促销手段单一，依赖降价引流

## 通用获客渠道优先级
1. **短视频（抖音/视频号）**：最通用的获客渠道，适合任何行业
2. **本地生活平台**：建立线上存在，让客户能找到你
3. **微信生态**：朋友圈+视频号+社群，低成本私域运营
4. **行业垂直平台**：根据行业选择（如B2B选阿里巴巴、1688）
5. **线下口碑**：做好客户体验，让客户主动传播

## 通用关键指标
- 品牌曝光量（每月线上触达人数）
- 咨询量/线索量
- 到店率/响应率
- 成交率/转化率
- 客户生命周期价值（LTV）

## 通用执行框架
1. **明确目标客户画像**：年龄、性别、地域、痛点、消费能力
2. **选择1-2个核心渠道**：不要贪多，先在一个渠道跑通
3. **持续输出内容**：每周至少3条内容，建立专业形象
4. **系统化收集线索**：建立客户信息表，跟进转化
5. **复盘迭代**：每周数据分析，优化投入方向

## 本周快速启动建议
1. 开通抖音/视频号企业号，完善账号信息
2. 分析目标客户画像，确定内容方向
3. 拍摄发布第一条内容（可以是介绍自己业务的短视频）
4. 整理现有客户信息，建立基础客户管理表
