# 地产客户画像与心理
# 版本: 2.0.0
# 用于诊断时分析客户定位和获客策略

## 核心客户类型

### 1. 刚需购房者（25-35 岁）
**特征**：
- 首次购房，预算有限（100-200 万）
- 关注：总价、首付、月供、学区
- 决策周期：3-6 个月
- 信息渠道：短视频、小红书、朋友推荐
- 痛点：怕买贵、怕买到差房、首付不够

**沟通策略**：
- 用具体数字说话（"这套房月供比同户型少 2000 元"）
- 强调学区/保值性
- 提供首付方案建议
- 用真实案例建立信任

### 2. 改善型客户（35-50 岁）
**特征**：
- 换房需求，预算较高（300-800 万）
- 关注：居住品质、楼层、朝向、社区环境
- 决策周期：6-12 个月
- 信息渠道：小红书、朋友圈、实地考察
- 痛点：卖旧买新的衔接、换房成本、家人意见不统一

**沟通策略**：
- 强调生活品质升级（"这个楼层采光好，住着舒服"）
- 提供换房方案（"先卖后买 vs 先买后卖的利弊"）
- 做家人工作（分别和决策人沟通）
- 提供装修建议增值服务

### 3. 投资客户（30-55 岁）
**特征**：
- 以投资为目的，关注回报
- 预算灵活，看项目而定
- 关注：租售比、增值潜力、政策导向
- 决策周期：1-3 个月
- 信息渠道：行业报告、政策解读、圈子推荐
- 痛点：找不到好标的、担心政策风险、流动性

**沟通策略**：
- 用数据说话（"XX 板块过去 5 年均价涨了 30%"）
- 提供投资分析（租售比、持有成本、退出机制）
- 关注政策动态（"最新房贷政策对投资客的影响"）
- 推荐优质标的（而非普通房源）

### 4. 租房客户（22-40 岁）
**特征**：
- 短期居住，预算有限
- 关注：交通、配套、租期
- 决策周期：1-2 周
- 信息渠道：58 同城、豆瓣、同事推荐
- 痛点：租金上涨、押金纠纷、找不到合适房源

**沟通策略**：
- 快速响应（租房客户决策快，慢了就没了）
- 提供透明信息（真实房源、真实价格）
- 简化流程（线上签约、电子看房）
- 长租客户可考虑转化为购房客户

### 5. 商业地产客户（30-60 岁）
**特征**：
- 商铺/写字楼租赁或购买
- 预算大，决策链条长
- 关注：人流量、周边业态、合同条款
- 决策周期：3-12 个月
- 信息渠道：实地考察、行业资讯、专业代理
- 痛点：选址风险、合同陷阱、回报率不确定

**沟通策略**：
- 提供商圈分析（"这条街日均人流量 XX 次"）
- 做投资回报测算
- 协助谈判合同条款
- 提供选址建议（而非单纯推房源）

## 客户决策心理
1. **风险厌恶**：地产是大额消费，客户极度怕吃亏
2. **从众心理**："大家都在抢的房子不会太差"
3. **权威信任**：相信专业人士的判断
4. **情感驱动**：最终决定往往是"感觉对了"
5. **损失规避**：怕错过比怕买贵更严重

## 诊断时的客户分析方法
1. 确认主要服务的客户类型（1-2 种，不要贪多）
2. 评估对目标客户的了解深度（是否有画像？是否能说出痛点？）
3. 检查获客渠道是否匹配目标客户（如：服务改善型客户，就要做小红书）
4. 评估沟通策略是否匹配客户心理
