# 房产中介行业营销技能
# 版本: 1.0.0
# 适用行业: 房产中介/房产经纪

## 行业核心痛点
- 客户信任度低（"中介=赚差价"的固有印象）
- 业主和客户信息不对称
- 同行竞争激烈，靠网络房源获客成本高
- 从业人员流动大，经验难沉淀
- 客户找房周期长，容易流失

## 获客渠道优先级
1. **抖音/视频号**：实景看房视频、区域市场分析，打造专业IP
2. **小红书**：针对刚需/改善型客户，发布购房攻略、区域对比
3. **朋友圈营销**：每日更新房源，建立专业形象
4. **业主社群**：维护小区业主群，提供房产咨询服务
5. **本地论坛/贴吧**：分享购房知识，吸引精准客户

## 关键指标基准
- 月均带看量：20-30组
- 成交周期：客户首次咨询→成交 30-60天
- 转化率：带看→成交 5-10%
- 客单价：佣金1-3%
- 客户满意度：NPS 30+

## 客户心理特征
- 大额决策：买房/租房是大额消费，极度谨慎
- 信息焦虑：怕买贵、怕买到差房、怕被坑
- 需要专家：需要专业人士提供客观建议
- 理性决策：会反复比较多个房源和中介

## 推荐内容方向
- 实景看房Vlog（"带看XX小区3房2厅"）
- 区域市场分析（"XX板块值得买吗？"）
- 购房知识科普（"首次购房5大注意事项"）
- 业主访谈/案例
- 政策解读（"最新房贷政策影响分析"）
- 经纪人日常（真实工作状态展示）

## 本周快速启动建议
1. 拍摄3条实景看房短视频，展示专业度
2. 每周做一次区域市场分析的直播/短视频
3. 建立购房咨询群，定期分享政策和房源信息
4. 整理3个成功案例（客户画像+成交故事）
