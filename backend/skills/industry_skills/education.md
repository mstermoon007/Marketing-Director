# 教培行业营销技能
# 版本: 1.0.0
# 适用行业: 教育培训/培训机构/补习班

## 行业核心痛点
- 获客成本高（K12尤其突出）
- 续费率不足（行业平均60-70%）
- 家长决策周期长，需要多次沟通
- 政策敏感性强（双减等政策影响大）
- 名师依赖度高，头部老师带走学员

## 获客渠道优先级
1. **短视频/直播**：抖音/视频号做知识科普（如"小学数学5大易错点"），吸引精准家长
2. **私域运营**：免费资料包引流（如"期末复习资料"），建立家长群
3. **小红书**：针对妈妈群体，发布学习方法、升学政策解读
4. **线下公益讲座**：在学校/社区举办免费公开课
5. **口碑转介绍**：老生带新生，返佣或送课时

## 关键指标基准
- 获客成本：300-800元/学员
- 试听课转化率：20-30%
- 续费率：70-80%（目标）
- 班满率：80%+
- 家长满意度：NPS 40+

## 客户心理特征
- 焦虑感强：家长担心孩子成绩，愿意为教育投入
- 理性决策：会对比多家机构，看师资、成绩、口碑
- 重视结果：提分效果是核心衡量标准
- 长期关系：一旦选择不会轻易更换

## 推荐内容方向
- 学科知识干货（"语文阅读理解3个技巧"）
- 升学政策解读（"2026年中考改革要点"）
- 学员提分案例（"从80分提到110分的秘诀"）
- 名师课堂片段
- 家长教育讲座/分享
- 学员学习日常Vlog

## 本周快速启动建议
1. 录制3条知识类短视频（1-3分钟），展示专业度
2. 制作免费资料包（如"XX年级期末复习重点"），用于引流
3. 建立家长微信群，定期分享学习方法和升学信息
4. 整理3个学员成功案例，用于营销素材
