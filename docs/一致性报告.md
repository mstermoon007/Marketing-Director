### 任务 2：CORS 安全配置漂移清零

**状态**：✅ 已修复  
**对应审计项**：P0.2 — CORS `allow_origins=["*"]` + `allow_credentials=True`

**问题**：
- Starlette 在两配置同开时将请求方 `Origin` 原样回显，等效允许任意站点携带凭据调用 API

```diff
# src/api/main.py

+     [o.strip() for o in app_config.cors_allowed_origins.split(",") if o.strip()]

+     else ["http://localhost:3000", "http://localhost:5173", ...]

+ app.add_middleware(CORSMiddleware, allow_origins=_cors_origins, allow_credentials=False, ...)
```
- `allow_credentials` 改为 `False`
- 生产环境通过 `CORS_ALLOWED_ORIGINS` 环境变量精确配置域名

### 任务 3：数据库异步引擎漂移清零

**状态**：✅ 已修复  
**对应审计项**：P1.1 — 所有 async 路由用同步 DB 引擎阻塞事件循环

**问题**：
- `DATABASE_URL` 声明为 `sqlite+aiosqlite:///...`，但 `init_db` 替换掉 `+aiosqlite`，实际创建同步引擎
- 每个 `async def` 路由内 `SyncSession()` 是阻塞调用，在 asyncio 事件循环中串行化所有 DB 操作

**修复摘要**：
```diff
# src/db/models.py
- from sqlalchemy import create_engine
- from sqlalchemy.orm import sessionmaker
- engine = create_engine(DATABASE_URL.replace("+aiosqlite", ""))
- SyncSession = sessionmaker(bind=engine)
+ from sqlalchemy.ext.asyncio import AsyncSession, async_sessionmaker, create_async_engine
+ async_engine = create_async_engine(DATABASE_URL, echo=False)
+ AsyncSessionLocal = async_sessionmaker(bind=async_engine, class_=AsyncSession, expire_on_commit=False)
+ async def get_db() -> AsyncSession:
+     async with AsyncSessionLocal() as session:
+         yield session
```
- 新增 `_init_db_async()` 异步建表
- `init_db()` 自动检测运行中的事件循环，避免 `asyncio.run()` 冲突

### 任务 4：文件上传安全漂移清零

**状态**：✅ 已修复  
**对应审计项**：P1.2 — 仅扩展名校验无 magic byte；P1.3 — 文件名拼接存在路径遍历风险

**问题**：
- 上传仅比对扩展名集合，未校验 magic bytes
- 原始 `file.filename` 原样拼入路径，`../` 可导致路径遍历

**修复摘要**：
```diff
# src/api/review.py 新增三个安全函数
+ _ALLOWED_EXTENSIONS = { 扩展名 → (magic_prefix, offset) }
+ def _validate_magic_bytes(content: bytes, ext: str) -> bool:
+     """校验文件内容头部 magic byte 是否与扩展名匹配。"""
+ def _generate_safe_filename(original_name: str, content: bytes) -> str:
+     """服务端随机命名 + 扩展名白名单 + magic byte 校验。"""
+ def _safe_write_file(content: bytes, filename: str) -> Path:
+     """写入前 target.resolve() 校验仍在 UPLOAD_DIR 内。"""
```
- 原始文件名完全丢弃，改为 `{uuid}_{timestamp}.{ext}`
- CSV/TSV 跳过 magic byte（文本格式无固定头部），其余所有格式强制校验
- 写入前 `target.resolve()` 路径边界检查

### 任务 6：JWT 鉴权漂移清零

**状态**：✅ 已修复

**问题**：

- `login` 接收 `wx.login()` code 但从不向微信校验
- 全仓无任何路由对 token 验签

**修复摘要**：
```diff
# src/api/auth.py
- def _generate_mock_jwt(user_id, openid) -> str:
-     mock_signature = "dev-only-insecure-signature-CHANGE-ME"
-     return f"{header}.{payload}.{mock_signature}"
+ def create_access_token(user_id: str, openid: str = "") -> str:
+     secret = _get_jwt_secret()  # 强制来自环境变量 JWT_SECRET_KEY
+     payload = {"user_id": user_id, "openid": openid, "iat": now, "exp": ...}
+     return jwt.encode(payload, secret, algorithm=app_config.jwt_algorithm)
+ def verify_token(token: str) -> dict:
+     return jwt.decode(token, secret, algorithms=[app_config.jwt_algorithm])
```
- 移除 WeChat `code2session` mock 回退
- 8 个 router 文件全部添加 `dependencies=[Depends(get_current_user)]`
